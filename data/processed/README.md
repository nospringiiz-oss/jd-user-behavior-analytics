# Processed Data

Cleaned and transformed data is stored in MySQL analytical tables rather than exported as local CSV files.

Main processed tables include:

- dim_users
- dim_products
- fact_comments
- fact_user_product_daily
- mart_user_summary
- mart_product_performance
- mart_category_performance
- mart_brand_performance
- mart_daily_performance
- mart_hourly_performance

Local processed files are excluded from GitHub.
